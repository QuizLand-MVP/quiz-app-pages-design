# Quiz Land Styling Rules

## Colors

Use only guideline tokens unless explicitly updating the brand system.

Primary background: `#fbf5ef`
Panel: `#fffdf9`
Text: `#12324a`
Muted text: `#667689`
Line: `#eadfd5`

Accent colors:
- Blue: `#375ea3`
- Blue action: `#2f70e6`
- Coral: `#ef8d6b`
- Coral dark: `#df6f4f`
- Yellow: `#f4c95f`
- Teal: `#35a6a2`

## Typography

Use:

```css
font-family: "Baloo 2", "Nunito Sans", "Inter", sans-serif;
```

Functional pages should use smaller type than landing pages.

## Buttons

- Functional app/admin primary buttons: blue
- Marketing CTA buttons: coral gradient
- Secondary buttons: cream/white with subtle border

## Cards

- Border: `var(--line)`
- Radius: 20–24px
- Shadow: soft only
- Avoid dense borders and divider-only lists when cards are requested

## Responsive

- Mobile width target: 360px
- Desktop width target: 1280px
- Dense grids collapse to one column on mobile
