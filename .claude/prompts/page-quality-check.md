# Prompt — Quiz Land Page Quality Check

Review the changed Quiz Land page against the design system.

## Check

- Does it use `#fbf5ef` background?
- Does it use the transparent shared logo?
- Are cards rounded 20–24px?
- Are labels/eyebrows coral pills when appropriate?
- Are functional primary buttons blue where requested?
- Are marketing CTAs coral gradient?
- Is the copy short and playful?
- Does mobile layout work at 360px?
- Does desktop layout work at 1280px?
- Are answer grids one column on mobile where required?
- Are CSS files in root-level `css/<area>/`?
- Is the page linked from `pages.html`?

## Reject if

- Old blue-outline card style appears
- Non-transparent logo appears
- CSS is placed next to page HTML instead of root `css/`
- Layout breaks on mobile
- Large title fonts overpower functional screens
