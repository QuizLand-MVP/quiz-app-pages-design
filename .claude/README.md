# Claude Code Instructions for Quiz Land

This folder contains Claude Code instructions for working on the Quiz Land UI repository.

## Recommended usage

Copy `CLAUDE.md` to the root of the repository:

```bash
cp claude-code-instructions/CLAUDE.md ./CLAUDE.md
```

Keep the rest of this folder in the repo if you want reusable prompts and command templates.

## Included files

```text
claude-code-instructions/
├── README.md
├── CLAUDE.md
├── commands/
└── prompts/
```

## Main rule

Claude Code should treat these files as the source of truth, together with:

```text
quiz-land-brand-ui-guidelines.md
quiz-land-brand-ui-guidelines-v2.docx
quiz-land-pages/
```

Do not reintroduce older generated UI styles.
