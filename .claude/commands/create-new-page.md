# Claude Code Command — Create New Quiz Land Page

Use this prompt when creating a new static design page.

## Task

Create a new Quiz Land static HTML/CSS page.

## Requirements

1. Read `quiz-land-brand-ui-guidelines.md` first.
2. Follow the existing `quiz-land-pages/` structure.
3. Place HTML in the correct area folder:
   - `admin/`
   - `host/`
   - `game/`
   - `login/`
4. Place CSS in the matching `css/<area>/` folder.
5. Use shared assets only:
   - `../assets/quiz-land-logo.png`
6. Use current brand tokens.
7. Make mobile responsive.
8. Add a link to the new page in `quiz-land-pages/pages.html`.

## Do not

- Do not create a new visual language.
- Do not use old non-transparent logo files.
- Do not duplicate assets inside page folders.
- Do not use sharp enterprise dashboard styling.
- Do not use old blue-outline generated styles.
