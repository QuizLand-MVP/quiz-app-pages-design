# Claude Code Command — Update Existing Quiz Land Page

Use this prompt when updating an existing static page.

## Task

Update the requested Quiz Land page while preserving the current structure.

## Steps

1. Read `quiz-land-brand-ui-guidelines.md`.
2. Inspect the current page HTML and CSS.
3. Update only the page(s) requested.
4. Keep CSS in the mirrored root-level `css/` folder.
5. Preserve shared assets from `quiz-land-pages/assets/`.
6. Check both mobile and desktop layouts.

## Output expected

- Modified HTML/CSS files only.
- Brief summary of changed files.
- No unrelated rewrites.

## Design checks

- Cream background
- Soft panel/card shapes
- 20–24px rounded corners
- Guideline colors only
- Short playful copy
- Mobile-friendly layout
